# 📈 InvestBuddy

InvestBuddy is a modern stock market intelligence platform that helps users analyze stocks, view market trends, generate smart portfolios, track watchlists, and explore company insights using real-time financial data.

---

# 🚀 Features

- 🔐 Login & Register Authentication
- 📊 Real-time Stock Search
- 📈 1 Day / 3 Day / 5 Day Stock Predictions
- 🧠 Buy / Sell Suggestions
- 🏢 Company Overview & Competitor Analysis
- 📰 Live Financial News
- 📉 Interactive Stock Charts
- 💼 Portfolio Generator
- ⭐ Watchlist Management
- 🌙 Dark / ☀️ Light Theme Toggle
- 📱 Fully Responsive UI

---

# 🛠️ Tech Stack

## Frontend
- React.js
- Tailwind CSS
- Recharts
- Lucide React Icons

## Backend
- Flask
- SQLite
- yFinance API

---

# 📊 Prediction Logic

InvestBuddy uses:

- **Moving Average** - Analyzing price trends over specific periods
- **Trend Analysis** - Identifying market direction and momentum
- **Confidence Score** - Calculating prediction reliability based on historical accuracy

to generate short-term stock predictions.
